# Spinat Gnocchi
Author: Claudio
| | |
|---|---|
| **Kategorie** | italienisch |
| **Portionen** | 4 Personen |
| **Vorbereitungszeit** | 40 Min. |
| **Kochzeit** | 20 Min. |

![Titelbild](https://github.com/HB9GZE/MakersBestCooking/blob/main/images/spinat_gnocchi.jpg)

## Zutaten & Zubereitung

| Zutaten | Zubereitung |
|:---|:---|
| | **Schritt 1 — Brot einweichen** |
| 200g Tessinerbrot, 100ml Milch | Brot in kleine Würfel schneiden, in eine Schüssel geben und mit der Milch übergießen. Etwa 15 Minuten stehen lassen, bis das Brot die Flüssigkeit komplett aufgesogen hat. |
| | |
| | **Schritt 2 — Spinat vorbereiten** |
| 250g Blattspinat | Den Spinat kurz in einem Topf erwellen bis er zusammenfällt. Danach in kaltem Wasser abschrecken, gut ausdrücken, damit überschüssiges Wasser entweicht, und fein hacken. |
| | |
| | **Schritt 3 — Teig herstellen** |
| 1 Ei, 30g Parmesan, 2-3 EL Mehl, Salz, Pfeffer | Den ausgedrückten Spinat, das Ei, den Parmesan und das Mehl zur eingeweichten Brotmasse geben. Mit Salz & Pfeffer würzen. Alles zu einem formbaren Teig kneten. Sollte der Teig zu klebrig sein, noch einen Teelöffel Mehl hinzufügen. |
| | |
| | **Schritt 4 — Gnocchi formen** |
|  | Mit zwei Esslöffeln kleine Nocken formen und auf ein Brett oder Backblech auslegen. Wer flink arbeitet, kann die Noken auch direkt nach dem formen ins siedende Wasser werfen. |
| | |
| | **Schritt 5 — Backofen vorheizen** |
|  | Backofen mit ofenfester Schüssel auf ca. 60-70°C vorheizen. |
| | |
| | **Schritt 6 — Portionenweise Kochen** |
|  | Einen großen Topf mit Salzwasser zum Kochen bringen und die Hitze reduzieren, bis das Wasser nur noch leicht siedet. Die Gnocchi portionsweise hineingeben. Sobald sie an der Oberfläche schwimmen, sind sie fertig (dauert nur 2–3 Minuten). |
| | |
| | **Schritt 7 — Gnocchi aufschichten und warmhalten** |
|  | Fertige Gnocchi mit einer Schaumkelle aus dem Waser entnehmen und schichtweise in die aufgewärmte Schüssel geben. Dann mit Parmesan bestreuen und mit geschmolzener Nuss-Butter beträufeln. Zurück in den Ofen bis zur nächsten Portion. |

---

## Anmerkungen

> Gnocchi Reste können im Kühlschrank gut einen Tag aufbewahrt und im Ofen oder der Mikrowelle wieder aufgewärmt werden.
